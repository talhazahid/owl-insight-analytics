# OwlInsight static frontend preview

This folder contains a standalone presentation of the OwlInsight homepage and
analytics dashboard interface.

## Open locally

Open `index.html` directly in a browser, or serve this folder with any static
file server.

## Included

- Semantic HTML
- Responsive dark and light themes
- Static analytics dashboard widgets
- A small client-side theme toggle

## Deliberately excluded

- Authentication and Google OAuth
- Google Analytics and Search Console API access
- Database models and migrations
- Billing and subscription logic
- MCP server and OAuth implementation
- WordPress transport and plugin code
- Environment variables, credentials, and deployment configuration

The production application remains in the private OwlInsight repository.
